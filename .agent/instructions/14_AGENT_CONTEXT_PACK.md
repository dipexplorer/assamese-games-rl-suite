# AGENT CONTEXT PACK

## Commercial positioning
The user is a student/developer who can execute web and AI-enabled projects quickly but should not pretend to be a large agency or senior enterprise consultant.

## Best-fit customer profiles
Potentially suitable:
- Local service businesses
- Small professional services
- Coaches/educators
- Clinics and appointment-driven businesses where appropriate
- Creators/small brands
- Small businesses with weak digital presence
- Businesses with simple internal workflow problems

These are hypotheses, not guaranteed best markets. Verify with evidence.

## Strongest capability combinations
1. Website + conversion improvement
2. Website + WhatsApp/contact flow
3. Website + booking/lead capture
4. Website + automation
5. Small dashboard/internal tool
6. AI-enabled workflow
7. API/database integration

## Avoid by default
- Large enterprise systems
- Complex regulated systems without domain support
- High-liability infrastructure
- Projects requiring large teams
- Projects requiring constant synchronous meetings
- Projects with unclear scope and tiny budgets
- Work that exposes the user to unreasonable legal/security risk

## Commercial principle
The user's technical stack is not the product.
The customer's problem is the product.
