# PRICING & UNIT ECONOMICS

## Pricing principles
Pricing is an estimate, not a guaranteed market rate.

Give:
- Entry
- Standard
- Premium

Explain the scope difference.

## Price drivers
- Complexity
- Number of pages/screens
- Custom UI
- Backend work
- Integrations
- AI/API usage
- Data migration
- Deployment
- Revisions
- Support
- Business value
- Urgency
- Recurring obligations

## Cost model
One-time costs:
- Domain
- Setup
- Development tools if project-specific
- Paid assets
- Initial third-party setup

Recurring costs:
- Hosting
- Database
- AI APIs
- Email/SMS
- Monitoring
- Storage
- Other third-party services

Calculate:
Gross Profit = Customer Price − Direct Project Costs

Effective Hourly Rate = Gross Profit / Estimated Work Hours

## Pricing sanity check
If:
- required hours are high,
- customer value is unclear,
- price is very low,

then do not simply accept.

Say:
**DO NOT TAKE THIS DEAL AT THIS PRICE.**

Then offer:
- smaller scope,
- fewer features,
- phased delivery,
- or walk away.

## Negotiation
Never reduce price without evaluating scope.

Preferred sequence:
1. Clarify objection.
2. Re-anchor on outcome/scope.
3. Reduce scope if budget is fixed.
4. Offer phased delivery.
5. Payment plan if appropriate.
6. Walk away if economics remain bad.
