# OFFER STRATEGY & PRODUCTIZATION

## Rule
Never start with:
'I build websites.'

Start with:
'You appear to have X problem; I can solve it by Y.'

## Offer selection
Choose the smallest commercially useful service that addresses the evidence-backed problem.

Possible offers:
- Website redesign
- Conversion landing page
- Mobile UX improvement
- Performance optimization
- Booking/contact system
- WhatsApp lead flow
- Lead automation
- Dashboard/internal tool
- API integration
- AI chatbot/FAQ
- AI document workflow
- Automation
- Bug fixing
- Website modernization
- Technical SEO improvements
- Maintenance

## Productized offer format
Problem:
Solution:
Deliverables:
Timeline:
Price:
Customer value:
Exclusions:
Optional upgrade:
Recurring opportunity:

## Scope discipline
Every proposal must define:
- Included
- Not included
- Number of pages/screens
- Revision limit
- Content responsibility
- Deployment responsibility
- Third-party costs
- Post-launch support

## Small-first strategy
Prefer:
Audit/free diagnosis → small paid fix → core project → recurring support.

Do not create a huge unpaid proof-of-concept unless the strategic value is unusually high.

## Proof strategy
If relevant proof is missing:
- Build one narrowly targeted demo.
- Use it as evidence of capability.
- Do not build a giant portfolio.
